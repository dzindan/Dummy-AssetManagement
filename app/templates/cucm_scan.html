CUCM Phone Scan

Live IP-phone inventory pulled directly from CUCM (extension, model, IP), plus each phone's serial number scraped from its own web page - finds phones CUCM knows about even before they're imported into Manage Assets. Cross-checked against the current Manage Assets state by IP: model, serial, and the assigned user recorded there. When Model or Serial is mismatched, click Update on that row to write the live CUCM value into the database. CUCM's API doesn't report a phone's actual assigned owner, so the User column is a best-effort match against the phone's Description text instead - treat a MISMATCH there as "worth double-checking", not certain, which is why User has no Update button.
