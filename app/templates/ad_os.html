Operating systems from Active Directory

Fills in the OS of PCs that a network scan has not read - switched-off ones too. AD has no serials, so each computer is matched to a PC by hostname (the name a scan read together with the serial), then by IP, then by a serial written in its AD name / description. A scan's own result is kept, unless the computer was used in AD after that scan. Nothing is changed in AD. Read as {{ scan_identity }}.

Computer's IP (from AD or its DNS name) → the one current PC with that IP in the reports. A stale DNS record or a wrong IP puts the OS on another PC, so these show as "AD (by IP)", never replace a scan, and an IP shared by several PCs is skipped. Takes a few minutes.
