Network Check

Pings every IP address recorded against a branch's current assets, pulls each live machine's PC serial, monitor serial, and currently logged-on user over the network, and compares that against what was imported - so a wrong serial or a mismatched user surfaces without walking the branch in person. When a value is mismatched, click Update on that row to write the live-scanned value into the database, or use Update All / Ignore All below once you've reviewed every mismatch. View Update Log

This only works for machines this app's computer can actually reach on the network (same LAN/VPN, WMI/RPC not blocked by firewall, and an account with admin rights on the target machines). A branch that can't be reached will simply show every IP as "No response" - that's a network/permissions issue, not a data problem.

PC/monitor serial, MAC, CPU, RAM. Uncheck for a faster scan (hostname/session/uptime only).
