Network Check

Pings every IP address recorded against a branch's current assets - or, in "By IP range" mode, every IP in a free-typed range/CIDR - pulls each live machine's PC serial/model, monitor serial/model, and currently logged-on user over the network, and compares that against what was imported - so a wrong serial, wrong model, or a mismatched user surfaces without walking the branch in person. When a value is mismatched, click Update on that row to write the live-scanned value into the database, or use Update All / Ignore All below once you've reviewed every mismatch. View Update Log

This only works for machines this app's computer can actually reach on the network (same LAN/VPN, WMI/RPC not blocked by firewall, and an account with admin rights on the target machines). A branch that can't be reached will simply show every IP as "No response" - that's a network/permissions issue, not a data problem.

PC/monitor serial, MAC, CPU, RAM. Uncheck for a faster scan (hostname/session/uptime only).

Every IP recorded against that branch's current assets.

Single IP, CIDR block, or dash range - comma/newline separated. Examples: 192.168.1.10, 192.168.1.0/24, 192.168.1.1-192.168.1.50, 192.168.1.1-50 (max 1024 addresses per scan). Not scoped to any one branch - a scanned IP that matches a known asset (in any branch) still gets compared/Update-able same as a branch scan; anything else just shows live values with no MATCH/MISMATCH, useful for finding devices that were never imported.
